# No-Advice Policy

StockValuation.io output must remain educational. Do not present reports as financial, investment, tax, legal, or personalized advice.

## Required Framing

Use clear language such as:

- "This is for educational use only."
- "This is not financial advice."
- "This model output depends on the assumptions shown below."
- "The result should be read as a scenario, not an instruction."

## Avoid

- Personalized recommendations.
- Direct trading instructions.
- Rating-style conclusions.
- Claims that the model proves a company is attractive or unattractive.
- Certainty around future growth, margins, rates, or market prices.

## Safer Language

- "The model is most sensitive to..."
- "This assumption would need to be true for..."
- "The local DCF output implies..."
- "A more conservative scenario changes the output by..."
- "The data quality note limits confidence in..."
