# Damodaran-Style Method Notes

Use these checks to interpret local DCF JSON. Do not do the valuation math yourself; use MCP output for all DCF values.

## Core Logic

- Value operating assets from expected free cash flow to the firm.
- Reinvestment links growth to capital needs through sales-to-capital and return-on-capital assumptions.
- Cost of capital should converge toward a mature-company level over the forecast.
- Terminal growth should stay bounded by mature economy and inflation logic.
- Equity value is operating asset value plus non-operating assets and cash, less debt-like claims, minority interests, and option value where present.

## Report Interpretation

- Compare model intrinsic value to market price as a model gap, not as an instruction.
- Explain which assumptions drive the gap.
- Treat large valuation changes from small terminal or discount-rate changes as sensitivity risk.
- Call out when the local service selects a longer projection template or changes the growth pattern.

## Data Limits

- Yahoo Finance data can be missing, stale, restated, or inconsistent across companies.
- Historical coverage is limited.
- Financial-sector companies are unsupported until governed support exists.
- Reference-data mapping is an anchor, not proof that the company will match industry medians.
